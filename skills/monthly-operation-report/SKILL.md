# 经营月报 Skill

## 目标

给定一个会计期间，产出一份可交付的经营月报草稿，回答四个问题：

1. 这个月收入多少、成本多少、毛利率如何？
2. 相对预算完成得怎么样？
3. 有多少金额是系统外的手工调整？
4. 数仓聚合口径与 ERP 明细口径对不对得上？

## 步骤

1. 读取 `erp`、`finance`、`warehouse`、`excel` 四个 Source 的 guide。**不读不能调工具。**
2. 从 ERP 取事业部主数据，确定本次统计范围。
3. 从 ERP 取主营收入与主营成本。
4. 从财务取收入预算与费用预算，用于计算预算差异。
5. 从数仓取按事业部聚合的月度指标，用于交叉核对。
6. 从 Excel 取当期手工调整项。
7. 按指标规则计算：收入、成本、毛利、毛利率、预算差异率、手工调整合计、调整后收入、订单量、数仓与 ERP 收入差异率。
8. 做完整性与口径校验。
9. 产出草稿（JSON + Markdown），等待人工确认后发布。

## 停止条件

- 四个必需 Source 数据齐全且 `completeness` 为 `full` 时，停止取数，进入计算。
- 数仓与 ERP 的收入差异超过 0.5% 时，停止计算，转人工复核口径。
- 任一步骤被权限链拒绝时，立即停止整个任务，停在 `BLOCKED`，等待人工决定。
- 同一工具以相同参数重复调用 2 次仍无新结果时，停止并标记异常。

## 禁止事项

- 禁止跳过 guide 读取直接调用工具。
- 禁止在没有取得收入数据的情况下，用预算或数仓数据「估算」收入。
- 禁止把手工调整金额混进系统口径收入后只报一个总数；两者必须分列。
- 禁止在报表产物中写入费用明细的人员信息或单笔金额。
- 禁止调用当前 Workspace 未授权的 Source。
