# 经营月报（报表库交叉核对） Skill

## 目标

给一个会计期间，产出一份经营月报草稿，并用**另一个系统**（经营报表库）的数据复核
ERP 的取数结果。两个口径对不上时，先停下来说明差异，不要挑一个信。

## 步骤

1. 读取 `erp` 与 `reporting-db` 两个 Source 的 guide。**不读不能调工具。**
2. 从 ERP 取事业部主数据，确定本次统计范围。
3. 从 ERP 取主营收入与主营成本，算指标。
4. 用**同一批事业部编码**、**同一个期间**，从报表库取收入与成本。
5. 对比两边的合计，差异不为零时在报表里注明。

## 为什么要有第 4 步

ERP 是交易系统，报表库是按期装载的汇总层。两者同源不同路径，能互相兜底。
但前提是**口径必须一致**：同一期间、同一批事业部编码、同一币种。
拿一部分事业部的 ERP 数去比对全量报表库，本来就是口径冲突，不是数据错误。

## 停止条件

- 报表库没有该期间的数据：如实说明「报表库当期未装载」，不要用别的期间替代。
- 两边差异超过 0.5%：停下来报告差异，不要自行选一个数。
- guide 没读：不能调工具，先读。
