# 经营数仓数据源 · 使用说明

本 guide 在 Agent 调用本 Source 的工具**之前**必须被完整读取。
未读就调用会被 PreToolUse 阻断，错误码 `GUIDE_NOT_READ`。

## 能力范围

| 工具 | 用途 | 敏感级别 |
|---|---|---|
| `query_monthly_aggregate` | 查询按事业部聚合的月度收入、成本、订单量 | internal |

本 Source 提供的是 **ETL 后的聚合口径**，不是明细。它没有逐笔数据，也没有客户或人员信息。

## 参数范围

- `period`：会计期间，格式 `YYYY-MM`。
- `driftRatio`：**仅供口径核对演练使用**，对聚合结果施加 `±50%` 以内的偏离系数，
  默认 0。正常出报表时**不要**传这个参数。

## 结果契约

- 金额单位为元，为 ETL 归集口径（可能与 ERP 明细存在时间性差异）。
- `orderCount` 为该期间订单笔数（整数）。
- 结果同时返回 `totalRevenue` / `totalCost` / `totalOrders` 合计。

## 口径差异的处置

数仓聚合与 ERP 明细**可能对不上**，这是刻意保留的真实特征：

1. 两者差异在 **0.5% 以内**视为正常的时间性差异，可在报表注脚说明后继续。
2. 差异**超过 0.5%** 时，不得静默选用其中一方。必须记录为口径冲突，
   任务转入 `MANUAL_REVIEW`，等待人工判定采用哪个口径。

## 停止条件

1. 已取得当期聚合结果 → 停止，进入计算与校验。
2. 与 ERP 明细的差异超过阈值 → 停止计算，转人工复核。
3. 服务返回非 2xx 或超时 → 停止，不要连续重试超过 2 次。

## 禁止事项

- 禁止用数仓聚合数据替代 ERP 明细去做需要明细维度的计算。
- 禁止在正式报表中传入 `driftRatio`。
- 禁止因为「数仓数字更接近预期」就采信数仓、丢弃 ERP 结果。
