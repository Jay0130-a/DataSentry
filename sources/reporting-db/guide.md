# 经营报表库（Postgres）

集团报表库的只读入口。这里提供的是**固定查询**，不是 SQL 编辑器。

## 能做什么

| 工具 | 用途 | 参数 |
|---|---|---|
| `list_business_units` | 列出所有事业部编码与名称 | 无 |
| `revenue_by_bu` | 按事业部汇总主营业务收入 | `period`（YYYY-MM）、`buCodes`（数组） |
| `cost_by_bu` | 按事业部汇总主营业务成本 | `period`（YYYY-MM）、`buCodes`（数组） |

## 使用顺序

1. 先调 `list_business_units` 拿到编码，不要把事业部名称当成编码传进来。
2. 再把**这些编码**原样传给 `revenue_by_bu` / `cost_by_bu`。
3. 同一次任务里，收入与成本必须用**同一个期间、同一批编码**——否则算出来的毛利没有意义。

## 不能做什么

- **不能写 SQL。** 每个工具的查询已经在配置里固定，模型只能填参数。传任何形似 SQL 的字符串都只会被当成参数值，查不到数据。
- **不能跨期间比较。** 一次调用只返回一个 `period` 的数据。
- **不能读未登记的事业部。** 编码必须来自 `list_business_units`。

## 数据口径

- 金额单位：元，保留两位小数。
- `revenue` / `cost` 都是按 `bu_code` 汇总后的值，不是明细行。
- 数据是按期装载的；某期没有数据时返回空数组，**不是错误**——这种情况应当如实标注为缺失，不要用别的期间填补。

## 停止条件

- 返回空数组：如实报告「该期间无数据」，不要重试、不要换参数碰运气。
- 查询报错：停下来并报告，不要换一组参数再试。
